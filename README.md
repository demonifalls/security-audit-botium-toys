# Security Audit: Botium Toys

## Project Overview

This project is a simulated security audit completed as part of the Google Cybersecurity Professional Certificate. The objective was to evaluate the security posture of a fictional organization, Botium Toys, by reviewing its existing security controls, identifying areas of risk, and assessing compliance with relevant security standards and regulations.

## Scenario

Botium Toys is a growing organization with both physical and digital assets. A risk assessment identified weaknesses in the organization's security controls and potential compliance concerns.

The audit involved reviewing the organization's current security environment and determining which controls and compliance practices were already implemented and which required improvement.

## Skills Demonstrated

- Security auditing
- Risk assessment
- Security controls assessment
- PCI DSS compliance
- GDPR compliance
- SOC controls
- Access control and least privilege
- Data protection
- Disaster recovery and business continuity
- Security remediation recommendations

## Key Findings

The assessment identified several security gaps, including:

- Lack of least privilege and separation of duties
- Lack of a disaster recovery plan and critical-data backups
- No intrusion detection system (IDS)
- Lack of encryption for sensitive information
- Inadequate password management
- Insufficient protection of customer and cardholder information
- Gaps in asset and data classification

Existing controls included a firewall, antivirus software, physical security controls, and measures supporting data integrity and availability.

## Recommendations

Based on the assessment, Botium Toys should prioritize strengthening access controls, protecting sensitive information through encryption, implementing reliable backups and disaster recovery procedures, deploying intrusion detection capabilities, and improving password management.

Additional attention should be given to asset and data classification and addressing identified PCI DSS and GDPR compliance gaps.
